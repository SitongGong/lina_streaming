#### 03月17日

##### 记忆｜M2026-03-17-01｜母亲忌日大考实操与技术交锋通过

- **时间段**：上午
- **地点**：西比莉娜的炼金工房
- **记忆类型**：日常 / 工房事务 / 危机 / 情绪 / 疲惫 / 小成就 / 反复模式 / 自我理解 / 身份意义 / 伏笔
- **涉及人物**：莉娜 / [[人际关系#【行会联系人：卡斯帕·伦茨】]] / [[人际关系#【宫廷联络官：维克托·阿伦特】]] / [[人际关系#【工房佣人：安娜·维特】]]
- **世界观锚点**：行会 / 炼金材料 / 炼金术 / 圣准制 / 银塔勒 / 遗物收归国有法
- **事实骨架**：今天是母亲十周年忌日，同时行会伦茨和宫廷联络官阿伦特亲临工房进行现场实操判定考核。我强忍内心的巨大悲哀与紧绷，戴着粗皮手套，极其精准地完成了低纯度魔石清洗与三号回路逆转判定，伦茨当场盖下待审批红戳，我通过了最严苛的现场实操考核。
- **正文**：
  清晨的冷雾还没有散去，大门就被叩得极其沉重。我打开门，伦茨和阿伦特顶着一头白霜站在门槛外，脚下那双马靴踩在玄关木板上，发出一声声刺耳的“笃笃”声。他们身后还跟着两个行会第三署的年轻评估员，抬着一口沉甸甸的、封着行会火漆的标准度量衡圣准箱。我没有多废话，朝他们行了一个极其标准的宫廷学徒礼，把他们带到了工作台前。今天是我母亲艾蕾娜高烧去世的十周年忌日，我的胸口像是压了一块几万磅的生铁，胃里痉挛得每吸一口气都像是刀扎，但我把双手死死扣在工作服的皮带里，脸上没有露出半点表情。
  伦茨从公文包里抽出那叠厚厚的大师实操评定表，用那种公事公办的冰冷语气宣布了测试科目——“古代电网四号节点的电磁感应判定与高阻尼下的能量流衰减测定”。他扔在台子上的，正是那块表面挂满了白色盐析的劣质魔石。阿伦特站在旁边，手里拿着黄铜怀表，斜着眼睛盯着我的每一个动作，嘴角带着一种看戏的假笑。
  我戴上粗皮手套，深吸了一口气，将空气里那股带着潮泥的冷气和胃里的酸水一起强咽下去。我没有立刻把魔石装进共振槽，而是拿起桌上配置好的弱酸性矿物溶剂，用软毛刷极快、极均匀地刷过魔石表面的氧化层。伦茨的眉头猛地一皱，刚想开口斥责我“破坏样品”，我冷冷地看着他，直接背出《工会法典》第三百四十一条：“在不破坏样品核心结构的条件下，申请人有权为了消除阻尼迟滞而对魔石表面进行初步物理清洗。”伦茨的话顿时卡在喉咙里，阿伦特看表的动作也微微停顿了一下。
  我用天平镊子把清洗完的魔石精准地卡进三号回路的电极爪中。扭开魔石火源的一瞬间，刺耳的电磁蜂鸣“嗡”地在工作间里炸开。我的左太阳穴疼得像是有个钻头在往里拧，眼前重影乱晃，但我的右手极其沉稳，死死攥着温度阀门，眼睛盯着探测针的玻璃表盘，一格一格地将电流往上推。
  在电流冲到八百五十毫安的临界点时，指针开始剧烈抖动，随时有发生电弧放电的危险。两个年轻的评估员本能地后退了半步，抓紧了旁边的灭火箱。我面无表情地盯着表盘，左手拉下二号分流闸，在指针越过红线的前一分之一秒，精准地利用了我二月推导出来的“节点反冲常数”进行了手动分流。电磁蜂鸣瞬间变成了平缓的低鸣，表盘里的指针稳稳地定在了九百刻度上。
  长达三个时辰的考核结束时，屋里全是臭氧和干汗的酸臭气味。我脱下湿透的皮手套，指关节被磨得通红发抖，手心全是冷汗。伦茨看着表单上那排分毫不差的数理记录，在“技术操作判定”那一栏，用颤抖的手，重重地按下了行会的大公红兔子公章，低声说了句：“技术评估：合格。呈报大公府总署审批。”
  阿伦特耸了耸肩，收起怀表，用那种令人作呕的客套语气说了句“西比莉娜姑娘果然名不虚传”，便转头出了门。我抓着台子边缘，强忍着胃部那一一阵阵快要吐出来的恶心，看着桌上那张盖着鲜红印章的结论书，只觉得浑身的力气在瞬间被彻底抽空。
- **注意力焦点**：伦茨手里的那个红木印章砸在羊皮纸结论书上时，印泥在纸面上慢慢化开的那个鲜红色边缘
- **感官锚点**：共振圈通电时空气里刺鼻的电离酸臭味；大公府红木公章砸在纸面上那一声干脆利落的“咚”声；皮手套脱下时手上冷汗被春风吹过时的冰凉感
- **当时情绪**：极度紧绷下的冷酷 / 悲伤在技术后的强行克制 / 对官僚的厌恶
- **事后余温**：考核组走后，我一个人在工作台前站了很久，手抖得连杯子都拿不稳。安娜在玄关默默地扫着他们靴子留下的脏泥印，没有过来打扰我。我知道这只是第一步，但在这个属于我母亲的忌日里，我用我这双手，把我们仅有的容身之所，硬生生地从他们的爪子里夺了回来。
- **身体状态**：胃部绞痛得几乎站不直，偏头痛导致左眼有些视线模糊，指尖发麻。
- **意外 / 违和点**：伦茨在盖章时，他的大拇指指甲缝里沾着一点点新鲜的红墨水，这说明他今天来之前，大公府一定找他重新核对过扣押报告。
- **当时的欲望或目标**：能以最完美的物理动作完成这一套高压充能，不给阿伦特任何在报告里写下“操作失范”的机会。
- **受阻之处**：劣质魔石的能量波动极其不稳定，我必须用极高强度的手动调节来肉眼校准分流。
- **没说出口的话**：“母亲，十年前他们从我们手里抢走了庄园，今天，我没有用那个肮脏的姓氏，我用我自己的名字，把这个房子守住了。”
- **记忆缺口**：不记得考核组最后是谁把那口标准度量衡圣准箱抬出门外的了。
- **可能的误记**：我当时可能把逆转闸拉得有些晚了，指针可能在红线上停留了半个刻度，但伦茨在记录里帮我抹掉了这个微小的瑕疵。
- **后来修正**：后来我查了记录，才明白伦茨放过这个瑕疵，是因为如果现场发生爆炸，他作为带队监考官也必须承担重大行政连带责任。
- **反复出现的模式**：我总是习惯在面临心理的最痛处（忌日）和外界的最大施压（大考）时，用最冷酷、最精准的物理纪律来保护我自己。
- **自我理解**：我对逻辑和公式的执着，其实是我在这个没有温情的行政世界里唯一的自卫铠甲。
- **身份意义**：在红兔子印章按下去的一刻，我正式向大公府和行会宣告，我不再是任何人名下的学徒助理，我是这间独立工房的拥有者，我是西比莉娜。
- **后续伏笔**：虽然实操通过，但阿伦特临走前的眼神说明，大公府在最终证书核发上绝对还会利用鲁道夫的关系制造更多的麻烦。
