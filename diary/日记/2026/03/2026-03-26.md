##### 记忆｜M2026-03-26-01｜托马斯送达合格回执与冷笑

- **时间段**：上午
- **地点**：西比莉娜的炼金工房
- **记忆类型**：日常 / 工房事务 / 小成就 / 情绪
- **涉及人物**：莉娜 / [[人际关系#【送件官：托马斯·布鲁克】]] / [[人际关系#【行会联系人：卡斯帕·伦茨】]]
- **世界观锚点**：行会 / 信使 / 书信
- **事实骨架**：上午托马斯送来考核合格的官方回执信件，我看着上面红色的防伪兔子公章和伦茨的签名，发出一声冷笑。
- **正文**：
  上午的大风把天上的云吹得极高，冷飕飕的太阳像个铜板。托马斯把马栓在篱笆上，靴子上沾着没干的黄泥浆。他从大皮挎包里拽出一个印有行会第三署火漆的硬封套，递到我手里，用他那沙哑的嗓门有些艳羡地嘟囔道：“恭喜啊，西比莉娜姑娘，总署那帮老爷总算把合格书吐出来了。”我用裁纸刀挑开封口，里面是一页沉甸甸的羊皮纸，正上方印着行会那只极其鲜红的“防伪兔子”钢印，下面则是伦茨那工整到有些死板的手写签名：“现场实操评估：合格。无安全及执业违规行为。”我看着那几行黑油油的墨水字迹，嘴角不由自主地往上撇了撇，发出一声极其轻微的冷笑。这半个月来，他们动用了大公府和清查署的全部行政规矩，想把我的钥匙强行没收，结果他们自己写下的法典反而成了我最硬的盾牌。
- **注意力焦点**：合格羊皮纸最下方伦茨签名处由于写字太用力而在纸背上留下的、凸起的淡褐色笔尖印痕
- **感官锚点**：硬皮封套拆开时干燥的蜂蜡和旧皮革味；托马斯斗篷上被风吹得发干的马汗气味；指尖摸过羊皮纸纸质纹理时的干涩感
- **当时情绪**：傲慢的痛快 / 讥讽的冷淡 / 彻底的释怀
- **事后余温**：托马斯走后，我看着这页合格书，心里的石头终于彻底落了地。不管清查署的芬克或者鲁道夫接下来还想搞什么手段，只要这只红兔子印章还在我的柜子里，我的山谷工房在法律上就拉起了高压防护网。
- **身体状态**：肩膀的肌肉彻底松了脑，右手指节的酸痛也减轻了许多，神清气爽。
- **意外 / 违和点**：伦茨的签名边缘有些抖，这不符合他平时写账单时的极度工整，他显然是在某种政治压力下心不甘情不愿地写下的。
- **当时的欲望或目标**：能把这页回执当成大衣内衬，贴身藏好。
- **受阻之处**：羊皮纸太硬了，折叠起来容易产生永久性的火漆断裂裂纹。
- **没说出口的话**：“伦茨，你天天跟我计较那半格罗申，最后还不是得乖乖用你的笔，来承认我的技术地位。”
- **记忆缺口**：不记得托马斯走时有没有帮我把院门关紧了。
- **可能的误记**：回执信的火漆兔子可能没有我记得的那么红，也许只是普通的干蜡红色。
