#### 03月29日

##### 记忆｜M2026-03-29-01｜细密春雨与摩挲坏铜扣

- **时间段**：午后
- **地点**：小院
- **记忆类型**：日常 / 天气 / 季节 / 情绪
- **涉及人物**：莉娜 / [[人际关系#【炼金术士：尼可拉斯·培根】]]
- **世界观锚点**：小院 / 天气 / 季节 / 衣着 / 饰品
- **事实骨架**：午后我在小院里淋着细密的春雨，手里摩挲着2015年行李箱上坏掉的旧铜扣，心里暗想昏迷的老师如果醒来也一定会认可我的计算。
- **正文**：
  下午天色阴沉沉的，细碎得像面粉一样的春雨斜斜地洒在花坛上，把泥土浇得呈现出一种油黑的光泽。我没有撑伞，穿着洗得发白的呢子旧外罩，站在杂物箱旁。我从口袋里掏出那枚已经氧化变黑、边缘有一半彻底断裂的旧黄铜箱搭扣，用手指指腹在上面粗糙的断口上来回摩挲。这枚扣子是 2015 年冬天我们被遣散离开阿尔滕庄园时，行李箱上被颠断的。十年来我一直把它带在身边，当成一个毫无用处的铜疙瘩。细小的雨丝落在我的眼睫毛上，冰冰凉凉的。我看着脚下水仙花刚刚结出来的蚕豆花苞，心里突然想到了还在环线城病房里躺着、毫无知觉的培根老师。如果他现在醒过来，看到我昨天在实操台上用那个他手稿里都没有完美闭合的“反冲常数”把三号回路在八百毫安下救了回来，他那张严肃的脸上，应该也会露出那种极其罕见、却又极其满意的赞许笑意吧。
- **注意力焦点**：旧铜扣断口处那一圈因为十年来反复摸索而磨得极其光滑、露出一抹发亮金黄的金属截面
- **感官锚点**：春雨落在干呢子斗篷上时淡淡的湿羊毛气味；铜扣断口处毛刺压在指头上的微痛感；雨丝扑在额头上冰凉武骨的清凉感
- **当时情绪**：平静的哀伤 / 对老师的想念 / 技术上的骄傲
- **事后余温**：把铜扣重新揣回兜里。虽然老师现在还躺在冰冷的白铁床上，但我用他教给我的这双手，已经在这山谷里站稳了脚跟。下月去首都答辩，我一定把他的名字和我的名字，一起写在总署的最终合格册上。
- **身体状态**：睫毛和发梢被春雨淋得湿漉漉的，脸上有些凉，但指尖很暖和。
- **意外 / 违和点**：这枚坏铜扣的黄铜纯度出奇的高，十年来居然没有长出一丁点绿色的锈斑，阿尔滕庄园以前用的料子确实比行会好得多。
- **当时的欲望或目标**：能让老师醒过来，听我亲口跟他讲完昨天我是怎么拉下分流闸的。
- **受阻之处**：首都与山谷相隔上百里，大公府的联络官封锁了病房的一切最新消息。
- **没说出口的话**：“老师，你快点醒过来吧，大电网的账目，我已经替你全部抹平了。”
- **记忆缺口**：记不清当时在旧屋离开时，我是不是把母亲最喜欢的那把木梳子也带出来了。
- **可能的误记**：这枚扣子也许并不是箱子上的，只是我从庄园马架下随便捡来的垃圾，我的记忆出于合理化反抗而套上了这个意义。
- **后来修正**：暂无。
- **反复出现的模式**：我总是习惯在获得阶段性专业成就后，通过抚摸童年的创伤遗物（坏铜扣）来强化我反抗生父家族的自我合理性。
- **自我理解**：我对技术独立的病态追求，本质上是我试图向那个放弃我的父亲证明，我不需要他的任何庇护依然能活得极好。
- **身份意义**：在春雨的小院里，我摩挲着旧铜扣，觉得西比莉娜这个姓氏的脊梁骨，已经被我用技术硬生生地撑得挺直了。
