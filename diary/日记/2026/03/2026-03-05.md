#### 03月05日

##### 记忆｜M2026-03-05-01｜收到3月17日考核公文与心沉

- **时间段**：上午
- **地点**：西比莉娜的炼金工房
- **记忆类型**：日常 / 工房事务 / 危机 / 情绪
- **涉及人物**：莉娜 / [[人际关系#【行会联系人：卡斯帕·伦茨】]] / [[人际关系#【宫廷联络官：维克托·阿伦特】]]
- **世界观锚点**：行会 / 遗物收归国有法 / 书信
- **事实骨架**：上午收到大公府与行会联合签署的官方日程文书，确定我的独立实操测试定于3月17日举行，我心中一沉，因为那天是母亲的十周年忌日。
- **正文**：
  上午的风很大，把工作间的大门吹得哐当直响。伦茨派来的驿站信使在雪融后的泥地里留下了一串深深的马蹄印。我拆开信封，展开那张盖有清查署蓝色双头鹰和大公府烫金兔子公章的公文。信上的字迹工整而冷酷：“兹定于共和历三月十七日，由大公府特派评估员与行会第三署联合组成考核组，赴梦幻省山谷工坊进行现场实操判定测试，逾期视为自动放弃所有权。”我的目光在“三月十七日”这几个字上停住了，像是有一根钢针直接扎进了后脑勺，两眼瞬间有些发黑。三月十七日，那是母亲在乡下旧屋高烧去世的十周年忌日。每年的这一天，我本该点燃蜡烛，把门窗锁死，一个人在安静里陪她一会儿，这是我唯一的私人边界。可现在，他们把那份剥夺工房的实操测试偏偏定在这一天。这意味着我不仅不能去想她，还得在伦茨和阿伦特那两双挑剔的眼睛下，去擦亮每一个砝码、去精准地记录供能电极数据。我把公文重重地按在桌面上，只觉得胃里一阵痉挛。
- **注意力焦点**：公文最上方那个印得有些歪斜、边缘沾了蓝色残墨的清查署双头鹰印戳
- **感官锚点**：信纸上干燥的油墨气味；门缝外灌进来的带有一股春泥腥味的穿堂风；胃部因为痉挛而发出的隐隐绞痛声
- **当时情绪**：窒息般的悲伤 / 强烈的反抗心 / 极度压抑的烦躁
- **事后余温**：在桌子前站了很久，手心冰凉。我看着窗外已经开始发青的花圃，发誓哪怕在忌日当天，我也绝不在他们的技术刁难面前露出半点虚弱，这是我唯一能为母亲保留的体面。
- **身体状态**：牙齿紧咬得太阳穴处的肌肉有些发酸，额头后部神经隐隐抽痛。
- **意外 / 违和点**：大公府的联署人里居然没有芬克的名字，看来他已经被高层排除在这次对我的终极清算之外。
- **当时的欲望或目标**：能把这封该死的日程公文揉成纸团扔进火炉。
- **受阻之处**：如果我拒绝这个日期，行会法典的托管期程序将自动失效，大公府可以立刻查封工房。
- **没说出口的话**：“母亲，十年前他们用一张行李清册把我们赶出庄园，现在他们又想用一张考核公文抢走我的房子。我绝不会让他们得逞。”
- **记忆缺口**：不记得当时信使来敲门时，门环响了几下。
