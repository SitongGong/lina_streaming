##### 记忆｜M2026-04-20-01｜劳赫意外登门与阿尔滕家族的阴影

- **时间段**：午后
- **地点**：临时住处
- **记忆类型**：日常 / 违和 / 社交 / 情绪
- **涉及人物**：莉娜 / [[人际关系#【书记员：埃米尔·劳赫】]] / [[人际关系#【新领主：鲁道夫·阿尔伯特·冯·阿尔滕】]]
- **世界观锚点**：新罗马 / 宫廷 / 封蜡 / 书信 / 信使 / 衣着 / 情绪
- **事实骨架**：阿尔滕家族的书记员劳赫突然找到我的临时住处，转达了新领主鲁道夫重新接纳我入籍并为其鉴定遗物的要求，并以执照扣发为威胁，我愤怒地拒绝了。
- **正文**：
  午后的雨刚停，门外突然传来了极其规律、沉重的敲门声。我拉开木栓，看到站在窄小走廊里的埃米尔·劳赫时，浑身的血液像是瞬间冻结了。他穿着一件极其体面的深蓝色羊毛呢斗篷，袖口上别着闪亮的黄铜袖扣，手里拿着一卷用红色封蜡封好的羊皮纸，神态和十一年前在庄园长廊里驱逐我与母亲时一模一样。他用那种公事公办、没有一丝温度的腔调，称呼我为‘西比莉娜小姐’，并递上新领主鲁道夫·阿尔伯特·冯·阿尔滕的召回文书。他说鲁道夫愿意重新接纳我入籍，前提是我必须回庄园为阿尔滕家族服务，否则大公府的大师执照将‘因背景合规问题而无法核发’。看着他那张由于养尊处优而有些发福的脸，我只觉得胃里翻江倒海般地恶心。那枚带有阿尔滕家族猫头鹰钢印的封蜡在我眼前晃动，像是一把生锈的铁剪，把我好不容易在山谷里缝补起来的自尊再次剪得粉碎。十一年前，他们用几张冷冰冰的遣散文书把我们赶进风雨里；十一年后，他们又想用同样的格式把我的未来变成他们的附庸。我攥紧了藏在斗篷底下的手，指甲深深掐进肉里，脸上却冷得像一块大理石。我告诉他，这封信我不会接。
- **注意力焦点**：劳赫右手手指上那枚亮闪闪的、刻着阿尔滕家族猫头鹰徽章的纯银图章戒指边缘
- **感官锚点**：劳赫呢子斗篷上散发出来的、极其昂贵的熏香与首都马车马汗味混合的气味；他说话时公事公办、冷冰冰的手术刀般腔调；我指甲陷入掌心时带有的温热黏腻感
- **当时情绪**：极度的愤怒与恶心 / 被抛弃创伤的猛烈苏醒 / 誓死反抗的决绝
- **事后余温**：劳赫冷笑着转身离去时，我死死地关上了木门，整个人靠在门板上，抑制不住地战栗起来。我宁可在山谷里把指甲磨烂，也绝不会再回去当那个被拉上窗帘的、见不得光的小人物。
- **身体状态**：胃部因为极度恶心而发生严重的干呕，牙齿酸痛，两只大腿肌肉因为用力绷紧而发僵。
- **意外 / 违和点**：劳赫的措辞虽然极尽威胁，但他的眼神里却闪过了一丝局促，似乎新领主对他下达的这道指令其实也面临着某种时间上的压力。
- **当时的欲望或目标**：能把那封带有猫头鹰封蜡的羊皮纸直接摔在他脸上，让他滚出我的走廊。
- **受阻之处**：他是代表大公府的背景复核执行人员之一，如果直接发生肢体或言语冲突，执照审定流程会被立刻终止。
- **没说出口的话**：“你们的这个长廊，我这辈子都不稀罕。”
- **记忆缺口**：不记得当时劳赫的呢子大衣上是不是别着大公府的特许出入证章了。
- **可能的误记**：他说的重新入籍可能并非鲁道夫的恩赐，只是鲁道夫因为缺少遗物鉴定师而不得不采取的权宜之计。
- **后来修正**：后来罗莎琳德证实，由于巴比神殿的重置，阿尔滕庄园急需持有大公府执照的术士来重新核定他们的古代地契。
- **反复出现的模式**：一旦面临原生家族权力的直接压制，我童年的创伤就会完全转化为最极端、最具攻击性的自卫和决断。
- **自我理解**：我对阿尔滕家族的这种本能排斥，是我捍卫“西比莉娜”这个名字合法生存权的唯一方式。
- **身份意义**：在劳赫的威胁面前，我彻底划清了我和阿尔滕家族的最后一条红线。
- **后续伏笔**：劳赫临走时说的那句“我们会按照程序执行”，让我对明天的背景复核产生了最坏的预感。
