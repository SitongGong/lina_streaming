##### 记忆｜M2026-02-18-01｜密封“帝国独立大师考核申请书”的自立仪式

- **时间段**：午后
- **地点**：西比莉娜的炼金工房
- **记忆类型**：日常 / 工房事务 / 遗物鉴定 / 情绪 / 决断 / 伏笔
- **涉及人物**：莉娜 / [[人际关系#【炼金术士：尼可拉斯·培根】]]
- **世界观锚点**：手稿 / 抄本 / 行会 / 新罗马 / 银塔勒
- **事实骨架**：在工作台前，我仔细核对完“帝国独立大师考核申请书”的全部一百二十个条目，在两位担保大师和培根老师的盖章旁，重重盖下我自己的“西比莉娜”私印，用红色火漆将其彻底熔封。
- **正文**：
  午后的冷光把工作台照得丝毫不偏。那本厚重的硬皮登记册已经被我用铅笔和蓝墨水填得密密麻麻，每一个古代语技术词汇和执业数据都经过了我的反复校对，没有留下哪怕半个字符的瑕疵。在第七页的“申请人盖章”栏，我深吸了一口气，拿起那枚用山谷冷松木和黄铜雕刻而成的个人私印——那上面没有阿尔滕家族的鹰徽，只有我母亲留给我的西比莉娜花饰。我把印章浸透了红色的印泥，重重地按在白色的纸面上。印泥在纤维里洇开的那一瞬间，我仿佛能听到自己骨头里有什么东西彻底断开的声音。我不再是那个躲在老师衣角后面、因为害怕被大公府卫兵发现而低头的小学徒，我也不是那个在庄园长廊里不能被看见的私生女。我把老师那枚缺角的猫头鹰印章和两个联署印章排在旁边，拿起烧热的火漆分流勺，将滚烫的红漆倒在绳结上。当那块带有兔子防伪章的金属钢印重重压下去，发出“咔嗒”一声闷响时，红漆彻底冷却结硬。这份申请书是我给自己套上的最沉的锁链，但它也是我用来砸碎阿尔滕家族和清查署铁栅栏的唯一铁锤。
- **注意力焦点**：红色火漆在白纸绳结上慢慢融化、冒出细小气泡并逐渐凝固的那个圆形边缘
- **感官锚点**：熔化火漆时松香与虫胶的刺鼻气味；黄铜钢印压在滚烫火漆上时微弱的避让声；冷木印章握在手心里粗糙发凉的触感
- **当时情绪**：极度平静 / 释怀 / 决然的骄傲
- **事后余温**：盖完章后，我一个人在桌子前坐了半个时辰，看着那个红色的火漆封口发呆。我觉得那块新凝固的漆像是一枚勋章，虽然沉重，但它让我名下的山谷工房在法律上彻底建起了一座高墙，行会和伦茨如果想来抢，就必须先在考场上击败我。
- **身体状态**：因为用力盖章，右手虎口发酸红肿，胸口有一股热烘烘的痛快感，呼吸畅快。
- **意外 / 违和点**：在盖培根老师的猫头鹰印章时，我发现黄铜印章的底部有一道新划痕，这说明老师在出事测试前，曾经极其仓促地使用过这枚印章。
- **当时的欲望或目标**：把这个封存完整的考核件寄出，不给行会总署留下任何可以挑剔的物理封口瑕疵。
- **受阻之处**：熔化的火漆有些太稀了，险些滴在我的技术附录原件上。
- **没说出口的话**：“母亲，阿尔滕家族把我们丢在冷雨里，今天我自己用西比莉娜的名字，在大公府的法典上盖了章。”
- **记忆缺口**：记不清当时在炉子里加的是松木炭还是栎木炭了，只记得火光很红。
- **可能的误记**：我的黄铜印章可能没有我记得的那么重，在极度紧绷的心理仪式感下，我的感官放大了铁器的分量。
- **后来修正**：暂无。
- **反复出现的模式**：我习惯在做出一生中最重大且不可逆的决定时，通过一套近乎刻板的、极其精确的物理仪式来确认我的决心。
- **自我理解**：我对印章和火漆的这种庄严感，本质上是对我那被否认的身份尊严的强力找回。
- **身份意义**：封上这封信的一刻，我完成了从被保护的学徒到自担风险的执业者的心理加冕。
- **后续伏笔**：这封盖有猫头鹰和西比莉娜印记的申请书，在下半年的资格战中成了我合法产权争议的最高呈堂铁证。
