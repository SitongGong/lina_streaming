##### 记忆｜M2026-02-16-01｜给老书记员的担保问询信

- **时间段**：午后
- **地点**：西比莉娜的炼金工房
- **记忆类型**：日常 / 社交 / 被打扰 / 情绪 / 伏笔
- **涉及人物**：莉娜 / [[人际关系#【宫廷同僚：罗莎琳德·迈尔】]] / [[人际关系#【送件官：托马斯·布鲁克】]]
- **世界观锚点**：书信 / 信使 / 行会 / 新罗马
- **事实骨架**：我用沾满墨水的羽毛笔给行会总署退役的老书记员写信，请求其为我报考大师资格进行联合技术担保，在字里行间用技术辞令争取机会。
- **正文**：
  午后的阳光把工作台上的灰尘照得像是一场无声的细雪。我摊开一张从修道院带出来的粗草纸，用削尖了的羽毛笔，极其缓慢地在上面写信。这封信的收件人是行会总署退役的资深书记官长——也是罗莎琳德塞给我的纸条上写着的那位老人。我必须在信里用最严谨、甚至带有一点行会老派风骨的学术辞令，向他陈述我在古代语和遗物安全评估上的实际能力，并请求他看在老师培根过去的面子上，为我的大师考核申请书签下他的技术担保私印。笔尖在纸上划过，发出干涩的“滋、滋”声，我改了三遍草稿，把所有显得软弱或者像在乞求的词汇全部抹去，只留下客观的数据、我的鉴定记录和关于大回环安全隐患的技术推导。在这种人情博弈里，我那卑微的学徒身份只能换来怜悯，而唯有我手里的技术，才能换来对等的尊重。我把信折好，用猫头鹰印章盖上封蜡，交给了刚好来送件的信使。
- **注意力焦点**：羽毛笔尖上沾着的、因为温度太低而显得有些浓稠发紫的蓝黑色墨水滴
- **感官锚点**：油纸信封粗糙坚硬的麻纤维手感；熔化封蜡时清脆的“啪”声；窗外化雪水流过铁管的哗哗声
- **当时情绪**：极度紧绷 / 警惕 / 倔强的自尊
- **事后余温**：信被信使带走后，我看着自己沾满了蓝黑墨水的手指，觉得有些局促。这种需要向他人伸出请求之手的滋味让我觉得边界受侵犯，但我知道这是我通往大师之路上必须咽下的砂砾。
- **身体状态**：因为长时间高度专注书写，手腕酸痛得发抖，后颈僵硬。
- **意外 / 违和点**：信使今天表现得极其心急，甚至没等我把火漆完全吹凉就一把夺过信封塞进了公文筒，这说明路上的天气又开始变坏了。
- **当时的欲望或目标**：能用这封信彻底打动那位固执的老书记员，让他同意担保。
- **受阻之处**：老书记员已经退役多年，且一向以脾气古怪、拒绝与大公府人员接触闻名。
- **没说出口的话**：无。
- **记忆缺口**：不记得当时给信使的马打水时，水桶里的水是不是结冰了。
- **可能的误记**：我可能把信件的字句写得太傲慢了，在极度渴望独立的心态下，我的措辞经常会显得带刺。
- **后来修正**：暂无。
- **反复出现的模式**：在向外界寻求帮助时，我总是倾向于用最冷冰冰的学术和技术事实来包装，以此来掩盖我内心的不安与防备。
- **自我理解**：我对他人阻扰的不信任，让我习惯于把所有的交易都变成纯粹的技术博弈。
- **身份意义**：写下这封请求信，说明我正在利用我以前最讨厌的宫廷人脉来为自己建立防线，这是一种无奈的妥协。
- **后续伏笔**：这封信后来送到了老书记员手里，他的回复直接决定了我的报考大局。
